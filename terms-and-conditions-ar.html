4. المحتوى والسلوك المحظور — عدم التسامح إطلاقًا

لا يوجد أي تسامح مع المحتوى المسيء أو المستخدمين المسيئين في Babble. يُمنع عليك نشر أو إرسال أو بث أو قول أو مشاركة أي مما يلي في أي مكان داخل الخدمة — بما في ذلك الغرف والمنشورات والريلز والتعليقات والرسائل المباشرة وأسماء المستخدمين والنبذات وصور الملف الشخصي:

4.1 المحتوى المسيء

  • العُري أو المواد الإباحية أو المحتوى الجنسي الصريح أو المحتوى ذو الإيحاءات الجنسية.
  • التحريض الجنسي أو الدعارة أو بيع الخدمات الجنسية.
  • خطاب الكراهية أو الألفاظ المهينة أو المحتوى الذي يهاجم الأشخاص أو يحطّ من قدرهم على أساس العرق أو الأصل الإثني أو الجنسية أو الدين أو الإعاقة أو المرض أو السن أو الجنس أو الهوية الجندرية أو الميل الجنسي.
  • التحرش أو التنمّر أو الملاحقة أو التهديد أو الترهيب أو تحريض الآخرين على مضايقة شخص ما.
  • العنف الصادم أو المشاهد الدموية أو المحتوى الذي يمجّد العنف أو التطرف العنيف.
  • المحتوى الذي يروّج للإرهاب أو الجريمة المنظمة أو التنظيمات العنيفة.
  • المحتوى الذي يروّج لإيذاء النفس أو الانتحار أو اضطرابات الأكل أو يرشد إليها.
  • مواد الاعتداء الجنسي على الأطفال أو أي تصوير جنسي للقاصرين. نبلّغ الجهات المختصة عن ذلك دون أي استثناء.
  • المحتوى الذي يروّج للمخدرات غير المشروعة أو الأسلحة أو غيرها من السلع والخدمات غير القانونية.
  • الرسائل المزعجة أو الاحتيال أو التصيّد الاحتيالي أو المخططات الهرمية أو العروض المالية الاحتيالية.
  • البرمجيات الخبيثة أو الفيروسات أو أي شيء مصمم لإتلاف البرامج أو الأجهزة أو تعطيلها.
  • المحتوى الذي ينتهك حقوق النشر أو العلامات التجارية أو الخصوصية أو حقوق الصورة.
  • انتحال شخصية شخص آخر أو علامة تجارية أو جهة.
  • نشر المعلومات الخاصة بشخص آخر دون موافقته.

4.2 السلوك المسيء

  • إساءة معاملة المستخدمين الآخرين أو تهديدهم أو مضايقتهم، سواء في الغرف العامة أو في الرسائل الخاصة.
  • التحايل على حظر فرضه عليك مستخدم آخر.
  • إنشاء حساب جديد بعد المنع.
  • تقديم بلاغات كاذبة أو كيدية.
  • التلاعب بالهدايا أو العملة أو المستويات أو لوحات المتصدرين أو أي خاصية أخرى في الخدمة.
  • استخراج البيانات أو الهندسة العكسية أو محاولة الوصول غير المصرّح به إلى الخدمة.
